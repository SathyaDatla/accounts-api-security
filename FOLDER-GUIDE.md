# Repository folder guide

The repository root is the runnable lab. Keep .github, infra, k8s, policy, runtime, scripts, service, waivers, and Dockerfile at this level so GitHub Actions and local commands resolve their paths.

Product Documents is a reader-friendly collection of the walkthrough, threat model, decisions, and operational notes. The authoritative versions of the operational files also remain under docs at the repository root so links, workflows, and reviewer commands use one canonical location.

# Waivers
Each exception is a separate object in waivers.json: finding_id, rationale, compensating_control, owner, approver, issue_url, created_utc and expires_utc (UTC RFC3339; maximum 30 days; break-glass maximum 4 hours). CI fails when fields are absent, dates malformed, expiry lapsed or duration exceeds the limit.
The exact waiver file change must arrive in a GitHub-verified signed commit on protected main, with CODEOWNERS platform review, two approvals, no self-approval and no admin bypass. Configure those requirements in repository rulesets; GitHub settings are external to this archive. The commit signature binds the reviewed file bytes, and its review/CI run remains in the org audit history. Scanner-native suppressions must cite the waiver ID; expiry causes the pipeline to fail even if the suppression remains. No waiver is active here. Expiry blocks builds until removal or renewed approval.
